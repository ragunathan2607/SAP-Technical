# ZOO_CLASS_EXTRACTOR – class / interface extractor

Executable report `ZOO_CLASS_EXTRACTOR` dumps everything about one or many global classes and interfaces
(SE24 objects): metadata, relations, attributes, full method signatures, events, types, inherited components
and the complete source of all includes.

## Installation

SE38 → create executable program `ZOO_CLASS_EXTRACTOR`, paste `ZOO_CLASS_EXTRACTOR.abap`, activate.

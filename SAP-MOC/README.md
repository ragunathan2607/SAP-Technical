# SAP-MOC

ABAP developments for SAP EHS **Management of Change (MOC)** and **Issue & Activity Management (`/IAM/`)**.

| Development | Type | Description |
| --- | --- | --- |
| [`ZMOC_ACT_TEMPLATE_UPLOAD`](ZMOC_ACT_TEMPLATE_UPLOAD/) | Executable report `ZMOC_R_ACT_TEMPL_UPLOAD` | Excel upload of IAM / MOC activity templates, code groups, long texts and assignments with transport recording |

Add each new MOC development as its own sub-folder named after its main object, with a `README.md`.
